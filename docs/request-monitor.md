# Монитор действий сотрудников

Основной режим показывает **кто и что сохранил в платформе**: создание и завершение
задач, назначения, комментарии, изменения сотрудников, удаление/восстановление
и смену паролей. Источник — события приложения после фиксации транзакции БД.

## Запуск

На настроенном компьютере дважды откройте `Start-Monitor.cmd` или из корня проекта:

```powershell
python -X utf8 scripts/request_monitor.py
```

Иллюстрация формата (не реальные записи):

```text
02.11 10:20:00 | Иван Петров · сотрудник · ID 7
  Создал и отправил задачу №15 «Подготовить материалы»

02.11 10:21:00 | Администратор · администратор · ID 1
  Сменил пароль пользователя «Иван Петров»
```

Время — `Asia/Qyzylorda`. Имена и ID различают одновременную работу сотрудников.
Изменения из CRM отмечены. В лог не попадают пароли, хэши, Bearer-ключи, текст
комментария или тело формы. Входы, выходы и открытия страниц скрыты.

Откат транзакции не создаёт запись об успешном действии. Savepoint не публикуется
до фиксации внешней транзакции. Повтор создания из CRM не создаёт второе событие.
Сначала могут появиться последние записи провайдера, затем новые. События до
установки этой версии остаются в журнале сайта/API и не воспроизводятся задним
числом. После перезапуска последние строки могут появиться снова; в одном сеансе
повторы по ID скрываются. CLI-поток читается по поступлению, снимки обновляются
каждые 5 секунд. Доставка зависит также от Railway.

Ctrl+C останавливает только просмотр. После обновления скрипта перезапустите
уже открытый монитор, чтобы включился новый режим.

## Технический режим

```powershell
python -X utf8 scripts/request_monitor.py --http
```

Показывает GET/POST, HTTP-статусы и время ответа. Успешные CSS/изображения и
healthcheck скрыты; `--all` включает их. Ответ 302 означает перенаправление,
а не доказательство сохранения формы. Точная ошибка — в JSON-ответе или на сайте.
IP, query string, неизвестные пути, ключи и тела запросов не выводятся.

Последние 20 записей без ожидания новых:

```powershell
python -X utf8 scripts/request_monitor.py --once --lines 20
```

## Другой компьютер

Нужны Python 3.10+, данные часовых поясов и официальный Railway CLI:

```powershell
python -m pip install tzdata
npm install -g @railway/cli
railway login
python -X utf8 scripts/request_monitor.py --project YOUR_PROJECT_ID --service caspian-college
```

CLI использует аккаунт с доступом к проекту. Ключи CRM не нужны. Если CLI не
находится, добавьте `--railway "C:\path\to\railway.exe"`. На Windows монитор
ищет родной executable рядом с npm-обёрткой `.cmd`.

Для постоянных параметров: `%USERPROFILE%\.caspian-college-monitor\config.json`:

```json
{
  "project": "YOUR_PROJECT_ID",
  "service": "caspian-college",
  "environment": "production",
  "railway": "C:/path/to/railway.exe"
}
```

`railway` необязателен при доступности CLI через PATH. Пароли и токены в этот
файл не добавляются. При потере связи монитор подключается повторно, при истёкшей
авторизации предлагает `railway login`. Для просмотра компьютер должен быть включён.
Ограничения и кредиты Railway Free монитор не меняет.
